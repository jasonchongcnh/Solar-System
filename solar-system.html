Path-finding algorithm

How the route is found

The lab models each enabled hexagon as a graph node. Shared sides become connections, so the route can move only between adjacent modules.

  1. Build the arrayPlace modules on an axial hexagonal grid and merge matching sides.
  2. Create the graphRecord each shared side as a two-way link between module IDs.
  3. Maximize module coverageCompare connected routes and choose one that visits the largest possible number of enabled modules, even when a full route is impossible.
  4. Prefer a loopWhen routes cover the same number of modules, prefer a closed loop. Otherwise, show the longest open route.

The route visits each selected module once, returning to the start only for a loop. Disabled modules are excluded from the search.
